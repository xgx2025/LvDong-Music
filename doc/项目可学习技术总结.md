# 项目可学习技术总结

## Java 后端

- **原生 Servlet 开发** — 不依赖 Spring Boot，手写 Servlet/Filter/Listener，理解 Java Web 底层原理
- **反射机制** — `BaseServlet` 通过反射实现 `?action=methodName` 路由分发，理解动态方法调用
- **自定义注解** — `@ParamName` 注解配合反射做参数绑定，类似简化版 Spring MVC 的 `@RequestParam`
- **原生 JDBC** — 手写 SQL、`PreparedStatement`、`ResultSet` 映射，理解 ORM 框架底层在做什么
- **HikariCP 连接池** — 数据库连接池的配置与管理
- **ThreadLocal 事务管理** — 手动控制数据库事务提交/回滚
- **JWT 认证** — 双 token 方案（accessToken + refreshToken），理解无状态认证机制
- **Servlet 过滤器链** — CORS 处理、Token 校验的 Filter 实现
- **WebSocket** — 实时通信（`javax.websocket`）
- **雪花算法** — 分布式 ID 生成策略

## 前端

- **Vue.js（CDN 引入）** — 非构建工具方式使用 Vue，理解渐进式框架
- **Axios 拦截器** — 请求/响应拦截、token 自动注入与刷新
- **HLS.js 音频流媒体** — HTTP Live Streaming 播放技术
- **CryptoJS 客户端加密** — 页面加密/解密方案
- **Tailwind CSS** — 原子化 CSS 框架

## 多媒体处理

- **FFmpeg + HLS** — 音频转码与切片流媒体，了解 `HlsProcessor` 和 `HlsStreamingServlet` 如何协作实现在线播放

## 工程实践

- **Maven WAR 打包** — 传统 Java Web 项目的构建与部署流程
- **Tomcat 部署** — 理解 Servlet 容器的工作方式
- **三层架构** — Servlet → Service → DAO 的经典分层设计

## 总结

这个项目最大的价值在于"手写轮子"式的开发。没有用 Spring Boot、没有用 MyBatis/JPA，所有东西都是从底层原生实现的。这非常适合用来理解框架背后"到底在做什么"，比如 Spring MVC 的参数绑定、MyBatis 的数据库操作、Spring Security 的认证过滤，本质上都和这个项目里的实现思路类似。
